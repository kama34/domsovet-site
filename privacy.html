Политика конфиденциальности Domsovet Publisher

Дата вступления в силу: 2026-10-03

Кто и зачем использует приложение

Domsovet Publisher — внутренний инструмент владельца YouTube-канала «Домсовет». Приложение используется только владельцем канала и только для его собственного канала. Другим пользователям оно не предоставляется.

Какие данные и как используются

Приложение обращается к YouTube Data API и YouTube Analytics API, чтобы:

  • загружать ролики на канал владельца;
  • изменять метаданные этих роликов (название, описание, теги, обложку);
  • задавать расписание публикации;
  • читать статистику канала и его роликов.

Данные других пользователей приложение не собирает и не обрабатывает.

Хранение и передача

Токены доступа хранятся локально на компьютере владельца канала и никому не передаются. Данные, полученные через Google API, не продаются, не передаются третьим лицам и не используются для рекламы.

Соответствие правилам Google

Использование и передача информации, полученной из Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

YouTube API Services

Приложение использует YouTube API Services. На работу с ними распространяются Условия использования YouTube и Политика конфиденциальности Google.

Как отозвать доступ

Доступ приложения к аккаунту Google можно отозвать в любой момент на странице myaccount.google.com/permissions.

Связь

По вопросам, связанным с этой политикой, можно написать через канал: youtube.com/@domsovet_mult.
